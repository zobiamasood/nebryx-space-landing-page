## 🖼️ IMAGE OPTIMIZATION TIPS

### Before Adding to Website:

1. **Resize Images**:
   - Hero background: 1920x1080 (or 2560x1440 for retina)
   - Card images: 600x400
   - Hero images: 800x800
   - Logo: 200x200 (adjust per use)

2. **Compress**:
   - Use TinyPNG: https://tinypng.com/
   - ImageOptim (Mac) or FileOptimizer (Windows)
   - Target: 50-200KB per image

3. **Format**:
   - JPG for photos
   - PNG for graphics/logos
   - WebP for modern browsers (optional)
   - MP4 for videos

4. **CDN Delivery** (Optional - for production):
   - Use Cloudinary: https://cloudinary.com/
   - Allows on-the-fly optimization
   - Easy image manipulation

### Implementation in React:

```jsx
import Image from 'next/image'; // If using Next.js
// OR use regular img with srcSet for responsive images

<img 
  src="/images/hero/astronaut.jpg"
  srcSet="/images/hero/astronaut-small.jpg 640w,
          /images/hero/astronaut-medium.jpg 1024w,
          /images/hero/astronaut-large.jpg 1920w"
  alt="Astronaut"
  loading="lazy"
/>
```

## 💡 PRO TIPS

1. **Use Placeholder Images First**
   - Start with what you have
   - Replace with curated images later
   - This maintains workflow momentum

2. **Create Image Variants**
   - Mobile: 500x500
   - Tablet: 800x800  
   - Desktop: 1200x1200
   - 2x Retina: 2400x2400

3. **Lazy Loading**
   - Load images below the fold lazily
   - Improves initial page load

4. **WebP Format (Modern)**
   - Smaller file sizes (25-35% reduction)
   - Supported by all modern browsers
   - Fallback to JPG for older browsers

5. **Responsive Images**
   - Use srcSet for different screen sizes
   - Saves bandwidth on mobile
   - Improves performance
